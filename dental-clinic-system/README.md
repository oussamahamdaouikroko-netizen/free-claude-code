# نظام إدارة عيادة الأسنان — نسخة مجانية بالكامل

نظام بسيط واحترافي لإدارة عيادة أسنان في الجزائر، باللغة العربية، بتكلفة **صفر**:

- **Google Sheets** = قاعدة البيانات والواجهة الرئيسية.
- **Google Apps Script** = الأتمتة والحسابات (مجانا).
- **WhatsApp Business** = التواصل مع المرضى **يدويا** عبر روابط جاهزة (بدون أي API مدفوع).
- لوحة ويب اختيارية بسيطة تستضاف مجانا على Google Apps Script.

لا يحتاج النظام إلى: خادم، Node.js، اشتراك قاعدة بيانات، مفتاح API، أو أي خدمة مدفوعة.

---

## 1. ملفات النظام

| الملف | الوظيفة |
|---|---|
| `Code.gs` | الإعدادات العامة + قائمة الأدوات + الدوال المشتركة |
| `Setup.gs` | إنشاء الأوراق والعناوين + البيانات التجريبية + النسخ الاحتياطي |
| `Queue.gs` | تسجيل المرضى + قائمة الانتظار + البحث |
| `Finance.gs` | الزيارات + الدفعات (الإيرادات) + المصروفات |
| `Inventory.gs` | المخزون + المشتريات + تنبيهات النقص |
| `WhatsApp.gs` | قوالب الرسائل الجاهزة + روابط واتساب |
| `Dashboard.gs` | حسابات لوحة التحكم + لوحة الويب (اختيارية) |
| `Tests.gs` | اختبار ذاتي شامل (`تشغيل الاختبارات`) |
| `Index.html` | لوحة الويب الاختيارية (أرقام إجمالية فقط، بدون بيانات المرضى) |

> كل ملفات `.gs` و`Index.html` توضع **داخل مشروع Apps Script نفسه**.

## 2. التثبيت خطوة بخطوة (للمبتدئين)

### الخطوة 1: إنشاء جدول Google جديد
1. افتح [sheets.new](https://sheets.new) من حساب Google الخاص بالعيادة.
2. سمِّ الجدول مثلا: **إدارة عيادة الأسنان**.

### الخطوة 2: فتح محرر Apps Script
1. من القائمة العليا اضغط **الإضافات (Extensions)** ← **Apps Script**.
2. سيفتح مشروع جديد باسم "مشروع بدون عنوان".

### الخطوة 3: إضافة الكود
1. في محرر Apps Script، احذف محتوى الملف الافتراضي `Code.gs`.
2. افتح ملف `Code.gs` هنا في المستودع، انسخ **كامل** محتواه والصقه في `Code.gs` في المحرر.
3. اضغط زر **+** بجانب "الملفات" ← **Script** ← اكتب الاسم `Setup` (يُضاف تلقائيا `.gs`) ← الصق محتوى `Setup.gs`.
4. كرر نفس الخطوة لبقية الملفات: `Queue`, `Finance`, `Inventory`, `WhatsApp`, `Dashboard`, `Tests`.
5. اضغط **+** ← **HTML** ← اكتب الاسم `Index` ← الصق محتوى `Index.html`.

> الاسم المكتوب بدون الامتداد، لأن المحرر يضيف الامتداد تلقائيا.

### الخطوة 4: حفظ المشروع
اضغط **حفظ** (أيقونة القرص) أو `Ctrl + S`.

### الخطوة 5: تشغيل إعداد النظام والتفويض
1. حدّث صفحة Google Sheets (ستظهر قائمة جديدة اسمها **إدارة العيادة**).
2. إذا لم تظهر القائمة: أغلق الجدول وافتحه من جديد.
3. اضغط **إدارة العيادة** ← **إعداد النظام**.
4. أول مرة سيطلب Google **التفويض (Authorization)**:
   - اضغط **مراجعة الصلاحيات (Review permissions)**.
   - اختر حساب Google الخاص بالعيادة.
   - قد يظهر تحذير "التطبيق غير مُتحقق منه" (Google Apps Script غير مُنشر للعامة):
     اضغط **خيارات متقدمة (Advanced)** ← **الانتقال إلى المشروع (Go to ...)** ← **السماح (Allow)**.
   - هذا التحذير طبيعي لمشاريع Apps Script الشخصية؛ المشروع يعمل داخل حسابك فقط.
5. ستنشأ كل الأوراق التالية تلقائيا: `المرضى`، `قائمة الانتظار`، `الزيارات والعلاجات`، `الدفعات`، `المصروفات`، `المخزون`، `مشتريات المخزون`، `لوحة التحكم`، `الإعدادات`.

### الخطوة 6: اختبار النظام ببيانات تجريبية
1. اضغط **إدارة العيادة** ← **بيانات تجريبية (للاختبار)**.
2. اضغط **إدارة العيادة** ← **تشغيل الاختبارات** — يجب أن تظهر: "الاختبارات: X نجحت، 0 فشلت".
3. تصفح أوراق `لوحة التحكم`، `قائمة الانتظار`، `الدفعات` وتأكد من ظهور البيانات.

### الخطوة 7: حذف البيانات التجريبية
1. اضغط **إدارة العيادة** ← **مسح البيانات التجريبية**.
2. هذا يحذف كل السجلات التي تبدأ معرفاتها بـ `TEST-` فقط، ولا يمس أي بيانات حقيقية.

### الخطوة 8: البدء بالاستخدام الحقيقي
1. من القائمة: **تسجيل مريض جديد** ← ثم **إضافة إلى قائمة الانتظار** يوميا.
2. أثناء العمل: **بدء العلاج** ← **إنهاء العلاج** ← **تسجيل دفعة**.
3. سجّل مصروفات العيادة بـ **تسجيل مصروف** ومشترياتك بـ **تسجيل شراء مستلزمات**.
4. اضغط **تحديث لوحة التحكم** في أي وقت (أو فعّل التحديث التلقائي — الخطوة 9).

### الخطوة 9: مشاركة الجدول والنسخ الاحتياطي
1. **المشاركة**: اضغط **مشاركة (Share)** في أعلى الجدول وأضف حسابات الموظفين فقط.
   - اختر "المحررون" لمن يستقبل المرضى، و"العارضون" لمن يطلع فقط.
   - **لا تجعل الرابط عاما "أي شخص لديه الرابط" أبدا** — الملف يحتوي بيانات مرضى.
2. **النسخ الاحتياطي التلقائي**: استخدم **إدارة العيادة** ← **تصدير نسخة احتياطية** (ينشئ نسخة كاملة داخل مجلد في Google Drive باسم `نسخ احتياطية - عيادة الأسنان`).
3. **النسخ الاحتياطي اليدوي**: من Google Sheets: **ملف** ← **إنشاء نسخة**، واحفظ نسخة أسبوعيا على الأقل.
4. يمكن أيضا تفعيل التحديث التلقائي للوحة التحكم (اختياري):
   - في محرر Apps Script: اضغط على **المشروع ← المشغّلات (Triggers)** ← **إضافة مشغّل**.
   - الدالة: `updateDashboard` ← "من الجدول" ← "باستناد إلى الوقت" ← "ساعيا".

## 3. الاستخدام اليومي (شرح القائمة)

| الإجراء | ماذا يفعل |
|---|---|
| **إعداد النظام** | ينشئ الأوراق والإعدادات (مرة واحدة، ويمكن إعادة تشغيله بأمان) |
| **تسجيل مريض جديد** | يسأل الاسم ورقم واتساب والملاحظات ويسجّل المريض |
| **إضافة إلى قائمة الانتظار** | يضيف المريض لطابور اليوم برقم دور فريد ويقدّر وقت دوره |
| **بدء العلاج** | يغيّر حالة المريض إلى "قيد العلاج" |
| **إنهاء العلاج** | يغلق الدور ويطلب تفاصيل العلاج والسعر والموعد القادم، ويسجّل زيارة مع المبلغ المتبقي |
| **تسجيل دفعة** | يسجّل دفعة (كاملة أو جزئية) ويحدّث المبلغ المتبقي تلقائيا |
| **تسجيل مصروف** | يسجّل مصروفا واحدا (كهرباء، صيانة، رواتب...) |
| **تسجيل شراء مستلزمات** | يسجّل شراء المخزون، يزيد الكمية تلقائيا، ويسجّل المصروف مرة واحدة |
| **تحديث لوحة التحكم** | يحسب كل الأرقام من السجلات الفعلية ويعرضها |
| **تصدير نسخة احتياطية** | ينسخ الجدول كاملا إلى مجلد احتياطي في Google Drive |
| **بحث عن مريض** | يبحث بالاسم أو رقم الهاتف |
| **إرسال رسالة واتساب** | يجهّز رسالة عربية جاهزة ويفتح محادثة واتساب مع المريض |
| **إضافة صنف للمخزون** | يضيف صنفا جديدا للمخزون |
| **تحديث حالة المخزون** | يعيد حساب حالة كل الأصناف (متوفر / منخفض / نفد) |
| **بيانات تجريبية / مسحها / تشغيل الاختبارات** | للاختبار فقط |

**البحث السريع**: اكتب جزءا من الاسم أو رقم الهاتف في نافذة "بحث عن مريض".

## 4. واتساب — قوالب الرسائل وطريقة العمل

### القوالب الجاهزة (6)
1. تأكيد الموعد.
2. تذكير قبل الموعد بساعة.
3. إشعار باقتراب الدور.
4. إشعار جاهزية الطبيب.
5. تغيير الموعد.
6. تذكير بالدفع.

مثال:
> "مرحبًا [اسم المريض]، نذكّركم بموعدكم في عيادة طب الأسنان اليوم على الساعة [الوقت]. يرجى تأكيد الحضور. شكرًا لكم."

### طريقة الإرسال
1. اضغط **إرسال رسالة واتساب** ← اختر المريض ← اختر نوع الرسالة ← أدخل الوقت/التاريخ/المبلغ.
2. يفتح النظام رابط `wa.me` مع الرسالة مكتوبة مسبقا.
3. **ملاحظة هامة**: فتح الرابط **لا يرسل الرسالة تلقائيا** — يجب الضغط على زر **إرسال** داخل واتساب.

### تخزين أرقام الجزائر (مهم)
- **الصيغة المطلوبة عند التسجيل**: `0555123456` أو `06 55 12 34 56` أو `+213555123456`.
- النظام يحوّل كل الصيغ تلقائيا إلى الصيغة الدولية **`213` + 9 أرقام** (مثال: `213555123456`) وهي الصيغة التي يحتاجها رابط واتساب.
- الأرقام الجوال الجزائرية تبدأ بـ **05 أو 06 أو 07** فقط. الأرقام الأرضية (02/03/04...) غير مقبولة لأنها ليست أرقام واتساب.
- إذا رفض النظام رقما، أعد كتابته بدون رمز الدولة مثلا: `0770123456`.

### لماذا لا يوجد إرسال تلقائي؟
- خدمات الإرسال التلقائي الرسمية (WhatsApp Cloud API) **مدفوعة**.
- الطرق غير الرسمية (بوتات، أدوات أتمتة) **تحظر رقم العيادة** وتشكل خطرا على الخصوصية.
- الطريقة الحالية (رابط جاهز + إرسال يدوي) **مجانية 100% وآمنة تماما**.

## 5. القواعد المالية

- **كل دفعة تُسجّل على حدة** في ورقة `الدفعات` — تسمح بالدفع الجزئي.
- **المبلغ المتبقي** يُحسب تلقائيا لكل زيارة: `السعر الإجمالي - المدفوع`.
- **لا يُحتسب السعر الكامل كإيراد** إلا بعد استلام النقود فعليا (الإيراد = ما في ورقة `الدفعات` فقط).
- **منع التكرار**: إذا أُرسل نفس المبلغ لنفس المريض مرتين في نفس اليوم، يظهر تنبيه "دفعة مكررة" ويطلب تأكيدك. (حل مشكلة الضغط المزدوج على زر النموذج).
- **دفعة مقدمة**: إذا سجّلت دفعة لمريض بدون زيارة مفتوحة، تُسجّل تلقائيا كـ "دفعة مقدمة" ويمكن ربطها لاحقا بزيارته.

### شراء المخزون والمصروفات — تجنب الاحتساب المزدوج
- الإعداد `تسجيل مشتريات المخزون تلقائيا في المصروفات` = **نعم** (الافتراضي):
  كل شراء مخزون يُسجَّل **تلقائيا** في ورقة `المصروفات` مع علامة `[شراء مخزون: ...]`.
  **في هذه الحالة: لا تُسجّل شراء المستلزمات مرة أخرى يدويا من "تسجيل مصروف"** — وإلا احتُسب مرتين.
- إذا غيّرت الإعداد إلى **لا**: لن يُسجّل الشراء تلقائيا، وعندها **يجب** تسجيله يدويا من "تسجيل مصروف".
- التدفق النقدي في اللوحة = `المدفوعات المسجلة - المصروفات المسجلة` لهذا الشهر (كل سجل مرة واحدة فقط).

## 6. المخزون

- **إضافة صنف**: من "إضافة صنف للمخزون" (الاسم، الفئة، الكمية، الحد الأدنى، الوحدة، المورد).
- **تسجيل شراء**: يزيد الكمية تلقائيا ويسجّل تاريخ وسعر آخر شراء.
- **تنبيهات النقص**: كل صنف يصل للحد الأدنى يظهر في اللوحة ضمن "المستلزمات التي تحتاج إعادة شراء"، وحالته تتحول إلى **منخفض** (أو **نفد المخزون** عند الصفر).
- **الحماية من السالب**: لا يمكن تسجيل كمية شراء سالبة، وأي تعديل يدوي يجعل الكمية سالبة يتم التراجع عنه تلقائيا مع تنبيه.
- يمكنك تحرير الأصناف يدويا مباشرة داخل ورقة `المخزون` (الكمية/الحد الأدنى)، وسيتم تحديث الحالة تلقائيا.

## 7. الخصوصية وحماية البيانات

- الجدول **خاص** بحساب Google الخاص بالعيادة — لا تشاركه إلا مع الموظفين الضروريين.
- **لا تضع** أسماء المرضى أو أرقامهم أو تفاصيلهم العلاجية في روابط عامة أو رسائل جماعية.
- لوحة الويب (`Index.html`) تعرض **أرقاما إجمالية فقط** بدون أي بيانات تعريف بالمرضى.
  عند النشر اختر **"أنا فقط" أو "حسابات محددة"** (Who has access) — وليس "أي شخص لديه الرابط".
- الكود **لا يسجّل** بيانات المرضى في سجلات التشغيل (Logs).
- **لا تسجّل** معلومات طبية حساسة غير ضرورية في خانة "ملاحظات" (اكتفِ بما يلزم للعلاج).
- أمان حساب Google وصلاحيات المشاركة مسؤوليتك: فعّل **التحقق بخطوتين** على حساب العيادة.
- **النسخ الاحتياطي**: استخدم "تصدير نسخة احتياطية" أسبوعيا + "ملف ← إنشاء نسخة" عند الحاجة.

**إشعار خصوصية مختصر (يمكن نسخه لمرضاك):**
> "تُحفظ بياناتكم في نظام إدارة العيادة بشكل خاص، ولا تُشارك مع أي طرف ثالث إلا بموافقةكم أو إذا اقتضى ذلك القانون. يمكنكم طلب الاطلاع على بياناتكم أو تصحيحها في أي وقت عبر العيادة."

## 8. حصة Google Apps Script المجانية وقيودها

النظام مجاني بالكامل ضمن الحصص اليومية المجانية لحساب Google (المستهلك/المدرسة):
- **زمن أقصى للتنفيذ الواحد**: حوالي 6 دقائق (عملياتنا تستغرق ثوانٍ فقط).
- **زمن تشغيل يومي إجمالي**: حوالي 90 دقيقة لجميع عمليات المشروع (يكفي عيادة بأي حجم عملي).
- توجد حصص أخرى (عدد المشغّلات، الاستدعاءات...) — ملخصها الرسمي على صفحة Google:
  <https://developers.google.com/apps-script/guides/services/quotas>
- عند الاقتراب من أي حصة، يوقف Google مؤقتا تشغيل الدوال؛ العملية تعود تلقائيا في اليوم التالي.

### قيود يجب معرفتها بصراحة
| الميزة | الحالة |
|---|---|
| إرسال واتساب تلقائي | **غير متاح مجانا** — البديل: رابط جاهز + إرسال يدوي (موجود) |
| رسائل SMS / تذكير صوتي | غير موجودة (مدفوعة عادة) |
| تطبيق موبايل رسمي | غير موجود — الواجهة تعمل من متصفح الهاتف عبر Google Sheets / لوحة الويب |
| متزامن لحظي بين عدة أجهزة | Google Sheets نفسها متزامنة؛ تحديث اللوحة يدوي أو ساعي |

| المشكلة | الحل |

| قائمة "إدارة العيادة" غير ظاهرة | أغلق الجدول وافتحه من جديد |

| "صيغة رقم الهاتف غير صحيحة" | اكتب الرقم `05xxxxxxxx` بدون رمز الدولة |

| تريد البدء من الصفر | احذف كل الصفوف من الأوراق (الصف الأول = العناوين يبقى كما هو) |

## 11. نظرة تقنية للمطورين

- التواريخ تُخزَّن كنصوص `yyyy-MM-dd` والأوقات `HH:mm` — لتصفية موثوقة بدون مشاكل المناطق الزمنية.
- كل المعرفات تلقائية: `P-` (مريض)، `Q-` (دور)، `VS-` (زيارة)، `TX-` (دفعة)، `EX-` (مصروف)، `IT-` (صنف)، `PU-` (شراء).
- البيانات التجريبية تُعرَّف ببادئة `TEST-` في عمود المعرف لسهولة حذفها.
- الترميز: UTF-8، والواجهة RTL (`setRightToLeft(true)` لكل الأوراق).
- الدوال الجوهرية تنتهي بـ `_` (مثل `registerPatient_`)، وأزرار القائمة تستدعي `ui*` أو `menu*`.
- لاختبار المنطق برمجيا: `runTests()` (لا يحتاج اتصالا بأي خدمة خارجية).
